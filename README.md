## 🏰 About This Quest

> *"Every great journey begins with a single scroll..."*

This is the source code of my **personal portfolio website** — a pixel-art RPG-themed interactive experience built with **React 19 + Vite 8 + Tailwind CSS v4**.

Instead of a boring resume, I turned my portfolio into an **RPG side-scroller** complete with:
- ⚔️ A walking knight that follows your scroll progress
- 🔥 Torch lighting effects & dungeon environments
- 🌿 Animated falling leaves & swaying vines
- 🎮 RPG-style skill bars, stat cards, and dialogue boxes
- 🌙 Pixel clouds, star fields, and CRT scanlines
- 🗺️ Stage-based navigation (INTRO → HERO → SKILLS → QUESTS → CONTACT)

## 🚀 Getting Started

```bash
# Clone the dungeon
git clone https://github.com/jonathanhsa/portofolio-jonathan-hs.git
cd portofolio-jonathan-hs

# Install spells (dependencies)
pnpm install

# Enter the dev realm
pnpm dev
```

Open `http://localhost:8443` and begin your quest.
